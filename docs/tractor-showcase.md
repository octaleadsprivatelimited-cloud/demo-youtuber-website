# Homepage tractor showcase

The existing tractor section now appears directly after the hero, without changing the hero. The admin Homepage section can still hide it or change its title. Other sections keep their existing ordering.

## Content controls

Add or edit a record in Admin → Tractors. All three controls are optional:
- Show in Popular tractors: includes an available new model in Popular.
- Upcoming model: includes it in Upcoming and excludes it from Popular/Latest.
- Show In demand badge: displays the red badge only when explicitly enabled by an editor. It is not a calculated demand claim.

Latest contains published, available new models sorted by creation date. Saving edits does not move a model to the top. Used models are excluded from these three collections. Only saved images, engine HP and displacement values are displayed. No catalog records or sample model specifications were inserted.

Five cards appear on desktop; smaller viewports offer a swipeable row without a visible scrollbar. Tabs support keyboard arrows, Home and End. Price buttons link to the model's price section. View All links use the same filters and include the full published catalog rather than the first 24 records.

## Assets

The engine, settings and flame icons are from https://github.com/tabler/tabler-icons, with the MIT license retained at public/icons/tabler/LICENSE. Tractor photographs remain supplied by the admin panel.
